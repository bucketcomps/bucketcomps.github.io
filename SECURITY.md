# Security policy

Please report a suspected credential, private-path, game-data, or publication
boundary leak privately to the repository owner. Do not open a public issue
containing the suspected material.

This repository must remain safe to clone and publish in full. It must never
contain:

- game assets, ROM or executable data, encryption keys, or decrypted content;
- private wiki or private-repository copies;
- raw evidence, internal paths, hostnames, process details, or runtime payloads;
- secrets, tokens, account identifiers, or unpublished personal information.

The static-site checker enforces a small negative-exposure baseline. Human review
is still required.
