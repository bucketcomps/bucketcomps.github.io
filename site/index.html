preservation lab // public signal

Games deserve source code.

BucketComps recovers aging games into readable, verifiable, native builds. The public record stays honest: proof classes remain distinct, holds stay visible, and “playable” means gameplay with working save and load.

field rules
  1. Bring your own legally obtained game data.
  2. No ROMs, keys, or extracted assets in Git.
  3. The binary is evidence; recovered source is a hypothesis.
  4. Incremental proof beats percentage theater.
