# Contributing

Keep changes small, public-safe, and easy to audit.

1. Put only static public material in `site/`.
2. Use relative links for site-owned files.
3. Keep live data and media out of this repository.
4. Run `python3 scripts/check_site.py`.
5. Open a pull request; do not publish custom-domain changes with feature work.

Project-specific progress belongs in that game's public repository. This landing
page should summarize projects without becoming a second canonical scoreboard.
